# Hospital Mobility Project

A comprehensive IoT system for monitoring hospital patient mobility, equipment tracking, and safety alerting.

## Repository Structure

- **`hardware/`**: Microcontroller firmware (ESP32) and sensor calibration modules.
- **`backend/`**: Ingestion server, REST/WebSocket APIs, data models, and business logic.
- **`frontend/`**: Web dashboard for real-time monitoring, patient tracking, movement history, and alerts.
- **`docs/`**: Architecture diagrams, setup guides, and API specifications.
