# Frontend Dashboard

Web application for real-time patient mobility tracking, alert monitoring, and historical analysis.

## Structure
- \src/components/\: Reusable UI components.
- \src/layouts/\: Page layouts and navigation shell.
- \src/pages/\: Application views (Dashboard, Patients, LiveTracking, MovementHistory, Alerts, Settings).
- \src/hooks/\: Custom application hooks.
- \src/services/\: API clients and data fetchers.
- \src/context/\: State management and context providers.
